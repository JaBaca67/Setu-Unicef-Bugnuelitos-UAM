## Estado y límites

La base Flutter Android y el almacén local cifrado están implementados. El nuevo acceso, backend, paneles conectados y red mesh permanecen en diseño. El chat necesita internet; MINED y dirección no leen el chat ni el relato. Los manuales operativos son versiones de trabajo para validar, con plazos, responsables y contratos técnicos pendientes.

El prototipo usa exclusivamente datos ficticios. El proyecto académico no se presenta como producto oficial ni avalado por UNICEF, MINED o MINSA.
